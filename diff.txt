    Fix: Implement Mode C baud rate negotiation and robust OBIS parsing
    
    - Switched to dynamic baud rate negotiation (Mode C): The component now reads the requested baud rate from the meter's IDENT response and dynamically switches the UART speed, fixing read issues on strictly compliant meters.
    - Consolidated to a single UART bus for both TX and RX.
    - Replaced the strict generic OBIS parser with a more robust substring search (strstr) to reliably extract values even if the meter output deviates slightly from the standard.
    - Changed architecture from PollingComponent to CustomAPIDevice to allow manual triggering of reads via Home Assistant service / button.
    - Added new sensors for maximum periods, previous month history, operating hours, and detailed error codes.
    - Added fallback calculation for temperature difference if the meter does not provide it directly.
